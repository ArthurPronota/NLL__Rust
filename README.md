# NLL (Non-Lexical Lifetimes) в Rust

## Что такое NLL

**NLL** (Non-Lexical Lifetimes) — это **переработанный borrow checker**, появившийся в **Rust 2018 edition**. До NLL время жизни заимствования совпадало с **лексической** областью видимости (до закрывающей `}`). После NLL — с **последним использованием** ссылки.

**Ключевое:** заимствование живёт **до последнего использования**, а **не** до конца блока.

## Разбор примера

```rust
fn main() {
    let mut v = vec![1, 2, 3, 4, 5];

    let r1 = &v[0];       // shared borrow

    let r2 = &mut v;      // ← до NLL ошибка, после NLL ок
    r2.push(6);

    println!("{r2:?}");   // [1, 2, 3, 4, 5, 6]
}
```

### Что происходит

1. **`r1 = &v[0]`** — shared borrow.
2. **`r2 = &mut v`** — mutable borrow.
3. **NLL** видит: `r1` **больше не используется** после строки 4.
4. **Borrow** `r1` **заканчивается** — можно `&mut v`.

### До NLL (Rust 2015)

```rust
let r1 = &v[0];
// r1 «жив» до конца main → r2 нельзя
let r2 = &mut v;   // ❌ ошибка
```

**Borrow** `r1` жил **до конца** `{}` — **ложный** отказ.

**Ошибка:**

```
error[E0502]: cannot borrow `v` as mutable because it is also borrowed as immutable
```

### После NLL (Rust 2018+)

```rust
let r1 = &v[0];
// r1 больше не используется → borrow мёртв
let r2 = &mut v;   // ✅ можно
```

**Borrow** `r1` живёт **до последнего** использования.

## Как работает borrow checker

### 1. Анализ использования

**Borrow checker** **отслеживает**:

- где **создана** ссылка;
- где **используется** (последнее);
- где **заканчивается** её **lifetime**.

### 2. Liveness analysis

**Liveness** — **жива** ли ссылка **в данной точке** программы.

```
let r1 = &v[0];       // r1 создана, live
println!("{}", r1);   // r1 использована, live
// r1 мертва (dead) — больше не используется
let r2 = &mut v;      // ✅ можно
```

### 3. Конфликт

**Ошибка**, если в **одной точке**:

- **активна** `&mut T` **и** `&T`;
- **две** `&mut T`.

## Пример: ложный отказ до NLL

### Код

```rust
fn main() {
    let mut v = vec![1, 2, 3];

    let r = &v[0];
    println!("{}", r);   // ← последнее использование r

    v.push(4);            // ← r больше не нужна
    println!("{:?}", v);
}
```

### До NLL

```rust
let r = &v[0];   // r «жив» до конца блока
println!("{}", r);
v.push(4);        // ❌ ошибка: v уже borrowed
```

**Причина:** `r` «жив» **до конца** `{}`.

### После NLL

```rust
let r = &v[0];
println!("{}", r);   // ← последнее использование r
// r мертва
v.push(4);            // ✅ можно
```

**Причина:** `r` **мертва** после `println!`.

## Явный scoping (если NLL не помогает)

### Проблема

Иногда **NLL** **не может** доказать, что borrow **мёртв** (например, в **цикле** или **замыкании**):

```rust
let mut v = vec![1, 2, 3];
let r = &v[0];       // borrow
v.push(4);            // ❌ ошибка
println!("{}", r);   // r используется позже
```

### Решение 1: явный блок

```rust
let mut v = vec![1, 2, 3];
{
    let r = &v[0];    // borrow внутри блока
    println!("{}", r);
}                     // ← borrow заканчивается здесь
v.push(4);            // ✅ можно
```

### Решение 2: отдельная функция

```rust
fn print_first(v: &[i32]) {
    println!("{}", v[0]);
}

let mut v = vec![1, 2, 3];
print_first(&v);      // borrow заканчивается с функцией
v.push(4);            // ✅
```

### Решение 3: `drop`

```rust
let mut v = vec![1, 2, 3];
let r = &v[0];
println!("{}", r);
drop(r);              // ← явно «убиваем» borrow
v.push(4);            // ✅
```

**`drop(r)`** для ссылки — **no-op**, но **borrow checker** видит **конец** borrow.

## Сводная таблица

| | До NLL | После NLL |
|---|---|---|
| **Lifetime borrow** | До конца блока | До последнего использования |
| **Ложные отказы** | ✅ Много | ❌ Мало |
| **Явный scoping** | Часто нужен | Реже |
| **Edition** | Rust 2015 | Rust 2018+ |

## Практические примеры

### 1. Изменение после чтения

```rust
let mut v = vec![1, 2, 3];

let first = v[0];      // копия (i32: Copy)
v.push(4);              // ✅
println!("{}", first);  // 1
```

### 2. Итерация и изменение

```rust
let mut v = vec![1, 2, 3];

for x in &v {          // borrow
    println!("{}", x);
}                       // ← borrow кончается
v.push(4);              // ✅
```

**После NLL** — `for` **заканчивает** borrow **сразу** после цикла.

### 3. Условное использование

```rust
let mut v = vec![1, 2, 3];

if true {
    let r = &v[0];
    println!("{}", r);
}   // ← r мертва
v.push(4);   // ✅
```

### 4. Функция с borrow

```rust
fn sum(v: &[i32]) -> i32 {
    v.iter().sum()
}

let mut v = vec![1, 2, 3];
let s = sum(&v);        // borrow кончается
v.push(4);              // ✅
println!("{}", s);
```

## Итог

- **NLL** — **переработанный** borrow checker (Rust 2018+).
- **Borrow** живёт **до последнего использования**, а **не** до конца блока.
- **До NLL** — **ложные** отказы, когда ссылка **формально** жива, но **не используется**.
- **После NLL** — **меньше** ложных отказов.
- **Если NLL не помогает** — **явный scoping** (`{}`), **отдельная функция**, **`drop(r)`**.
- **В вашем примере:** `r1` **мертва** после `&v[0]` → `&mut v` **можно**.
- **Правило:** заимствование **заканчивается** там, где ссылка **использована последний раз**.
